## 第八轮：修提示窗外的方框

- 现象：提示卡外面浮一个硬边方框（用户截图）。逐像素量：窗口最外 3px 是灰 `(165,165,165)`，
  四角 224 沿圆角走 → 是**窗口外框**不是卡片描边。
- 根因：`ApplyPanelCorners` 里的 `DwmSetWindowAttribute(hwnd, 33, DWMWCP_ROUND)`。
  DWM 会沿**整个窗口矩形**补 1px 描边，而提示窗改分层后窗口 = 卡片 + 36 DIP 阴影余量，
  于是描边画在余量外沿，离卡片 36 DIP。
- 这是我第五轮改造引入的回归（窗口从"等于卡片"变成"卡片+余量"，圆角请求没跟着调整）。
- 修法：去掉圆角请求；Win10 的 `SetWindowRgn` 兜底保留；深色标记保留。
- 验证：白底抓屏三边非白 0 个（修前 165）；深色临时切 theme=dark 也是 0；面板未调用该函数故不受影响；
  28 警告；--shot/--shot-toast 正常；提示窗开着退出 0.08s。
- 排查要点：DWM 画的边框**不在窗口位图里**，必须抓屏逐像素比对才能和卡片自己的描边区分。

## 第九轮：毛玻璃底图跟桌面实时变化

- 现象：面板开着时背后窗口关了，玻璃里还留着它的影子。原因：底图只在弹出时抓一次。
- 关键实验：`SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` 只把窗口从**抓屏**里摘掉，
  屏幕上照常显示 → 重拍不需要隐藏窗口、不闪。该 API 只能由窗口所属进程调用（跨进程返回 err 5）。
- 实测坑 1：不加 `DwmFlush()` 时，每十几次会抓到自己的窗口（跳变上万像素）→ 玻璃偶发闪一下自反射。
- 实测坑 2：不能只比哈希——桌面光标闪烁一两个像素就会触发重画；改成逐像素比 + 24 像素容差。
- 性能：降采样从 GDI+ 双三次改成手写 4×4 盒式（4~6ms → 0.2ms）；抓屏 13ms → 6ms；
  间隔 400→700ms。面板开 2.08% 单核，关 0.00%。
- 老系统不支持排除标志时，`RefreshPanelBackdrop` 返回 false 会自己 KillTimer，退回旧行为。
- 验证：黑底窗口销毁后玻璃亮度 158.9→233.9（0.7s 内）；条纹背景无自反射；28 警告；退出 0.09s。
