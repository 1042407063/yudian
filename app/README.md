# 余电 · 程序说明

一个常驻任务栏的小工具：读无线鼠标 / 键盘 / 手柄的实时电量，电量低了弹卡片提醒。
纯本地运行，不联网、不装驱动、不需要任何运行库。

**运行环境**：Windows 10（1607 及以上）或 Windows 11，64 位。Win11 上右键菜单是圆角的，Win10 上跟系统一致是方角——各自都保持系统本来的样子。

界面截图和设计细节在 [`../docs/technical-notes.md`](../docs/technical-notes.md)，这里只说怎么用、代码在哪。

## 怎么用

双击 `build/yudian.exe`，托盘出现一个墨底闪电图标，然后：

| 操作 | 结果 |
|---|---|
| 左键单击图标 | 弹出面板，看每台设备的电量 |
| 右键单击图标 | 菜单：显示面板 / 立即刷新 / 刷新间隔 / 重置位置 / 开机自启 / 退出 |
| 电量低于阈值 | 自动弹一张小卡片提醒（同一台设备 30 分钟内只提醒一次） |

面板打开时如果设备刚睡醒没数据，点右上角的刷新按钮，或者晃一下鼠标把它唤醒。

**想让它开机自动启动**：右键菜单里勾上「开机自启」即可，程序会自己写入系统的启动项。

## 配置存在哪

`%APPDATA%\PeripheralBattery\config.ini`

这是一个纯文本文件，记事本就能改。常用的两项：

| 键 | 含义 | 默认 |
|---|---|---|
| `low_threshold` | 低于多少百分比开始提醒 | 20 |
| `notify_low` | 是否弹低电量提醒（1 开 / 0 关） | 1 |

改完重启程序生效。这个文件不在项目目录里，所以换电脑/重装不会丢，但也别指望跟着项目一起复制走。

## 代码怎么分工

五个源文件，一个文件管一件事：

| 文件 | 管什么 | 什么时候需要改 |
|---|---|---|
| `src/main.cpp` | 程序入口、后台定时扫描、配置文件、开机自启 | 改刷新节奏、加配置项 |
| `src/ui.cpp` | 托盘图标、面板、提示卡片、右键菜单 | 改长相、配色、动画、排版 |
| `src/providers.cpp` | 各个品牌的电量协议（罗技 / 索尼 / 迈从 / 飞智 / VGN 等） | **加一款新设备就改这里**，只需在文件末尾的 `kProviders` 加一行 |
| `src/hid.cpp` | 最底层的设备枚举与读写 | 一般不用动 |
| `src/selftest.cpp` | 纯函数自检：位提取、归一化、报文解码 | 改了上面任何一个解析函数，就在这里补一条用例 |
| `src/app.h` `src/hid.h` `src/decode.h` | 上面几个文件共用的数据结构与声明 | 跟着改 |
| `src/app.rc` `src/app.ico` | 版本信息与应用图标 | 换图标 |
| `src/app.manifest` | 告诉 Windows 这是支持 Win10/11 的程序（没有它，右键菜单会是老式方角） | 基本不用动 |

`providers.cpp` 里每条读取链路都统一成 `ScanCtx` 签名，并按 `kProviders` 表的顺序认领设备：
**先到先得**，通用兜底只处理没人认领的接口。所以加一条链路不用回头改别人的排除条件。

## 怎么重新编译

双击本目录的 **`build.bat`**，本机实测约 20 秒。看到这几行就是成功：

```
[2/4] compile + link...
[3/4] self test...
[4/4] done. subsystem=00000002 (GUI)
  D:\...\app\build\yudian.exe  xxxxxx bytes
```

`[3/4]` 是自检：编译完先用同一个 exe 跑一遍纯函数断言（`--selftest`）。
**自检失败时脚本会停下来**，把新 exe 改名成 `build/yudian.broken.exe`，不会留下一个能双击但已经坏掉的程序。
自检结果在 `build/selftest.txt`。

想单独看看编译器的警告（不阻断构建）：

```
build.bat check
```

它用 `-Wall -Wextra` 再编一份到 `build/yudian.check.exe`，警告条数和完整日志在 `build/warnings.txt`。

产物在 `build/`，可以直接删，重编就会再生成。

编译器要求：MinGW-w64（`g++`）。脚本会自己按顺序找，找不到会提示装在哪。
**编译器不要放在中文路径下**——链接器处理不了，这是踩过的坑。

## 出问题了

| 现象 | 先看这里 |
|---|---|
| 某款设备读不到电量 | `docs/technical-notes.md` 的「排查」一节 |
| 面板上少了一台设备 | 设备在休眠，晃一下鼠标；或者点刷新 |
| 图标不见了 | 任务管理器结束 `yudian.exe`，重新双击运行 |
| 想看程序到底在干什么 | 命令行运行 `yudian.exe --list 报告.txt`，会把扫描过程写成文本 |

`--list` 之外还有一批给开发者用的命令（`--shot` 截图、`--mock` 假数据、`--vendor` 厂商诊断等），
都在 `docs/technical-notes.md` 的「辅助命令」一节，日常用不到。
